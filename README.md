# QA Test Case Portfolio — Raamdhan Murugaprasath

This repo is a **sample showcase** of how I write and organize test cases and automation, drawn from 8+ years of QA work across web and mobile products (150–200+ test cases authored per release cycle, 8,000+ over my career). The real project files live in private, client-owned repositories and can't be shared here — this repo uses **generic, made-up examples** (a sample login/checkout flow) to demonstrate my format, structure, and the way I use AI tools to speed up test authoring.

## What's inside

- `sample-test-cases/` — a manual test case sheet in the format I use day to day: test ID, scenario, steps, expected result, priority.
- `automation-samples/` — a Playwright script showing how I go from a plain-English test case to working automation with AI assistance ("vibe coding" the test, then reviewing and tightening it by hand).

## My approach to AI-assisted testing

I use AI tools (Claude, GitHub Copilot) as a pair-tester: describe the scenario in plain English, let the AI draft the test case or automation script, then review, correct edge cases, and validate it against the real app before it goes into the regression suite. This has let me author test cases faster and keep automation coverage growing alongside manual regression — without cutting corners on review.

## Note on scale

Across my current and recent projects, I've authored and maintained **8,000+ test cases** covering functional, regression, and release testing for web and mobile products. Specific project details are confidential; this repo exists to show *how* I work, not the private test data itself.
